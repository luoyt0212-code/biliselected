# Biliselected

给小学四年级孩子的「AI 探险主线」：家长手选的 B 站视频 + 游戏式成长系统。核心目标只有一个——**让孩子爱上人工智能**，配上科学、数学、编程和运动里的科学开眼界。原则是「点开就看、看完就停」，不是无限刷。

思路参考了 [limin112/bilipicks](https://github.com/limin112/bilipicks)，针对 8～10 岁、喜欢击剑和匹克球、要学英语的孩子重新设计。

## 打开方式

- 线上（iPad 用）：https://luoyt0212-code.github.io/biliselected/ （GitHub Pages，推送 `main` 后约 1 分钟更新）

- 直接双击 `index.html`（纯静态，不需要服务器）
- 或本地起一个服务：`python3 -m http.server 8765`，访问 http://localhost:8765

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` | 页面骨架 |
| `styles.css` | 样式（自动深浅色、手机适配） |
| `app.js` | 路由、成长系统、播放页、家长页 |
| `data.js` | **自动生成**的数据，不要手改 |
| `manifest.webmanifest`、`icons/` | iPad「添加到主屏幕」用的图标和配置 |
| `tools/curation.json` | 人工编排：关卡、推荐理由、知识小测、动手任务、英语单词（含例句）、淘汰记录 |
| `tools/build_data.py` | 通过 B 站公开接口核验每个 BV 号，生成 `data.js` 和筛选记录 |
| `docs/curation-log.md` | 自动生成的视频筛选记录（给家长检查） |

## 改内容

1. 改 `tools/curation.json`（加视频、改理由、改任务）
2. 运行 `python3 tools/build_data.py`（会逐条请求 B 站接口核验，约 1～2 分钟）
3. 任何入选视频核验失败，脚本直接报错、不写文件——**保证页面上不会出现编造或失效的视频**

## 成长系统规则

- **主线 7 关**按顺序解锁：上一关看完 2/3 的视频解锁下一关（`app.js` 的 `isStageUnlocked()`）
- **支线 3 条**（赛场上的科学、自然探索、历史与文明）随时可看
- **今日能量**：默认每天 2 格，打开一条今天没看过的新视频用 1 格；用完显示「今天到这里」。家长页可调 1～5 格或临时奖励
- **打卡**：在播放页停留到视频时长的一半（最多 4 分钟）后才能点「我看完了」
- **知识小测**：每条视频 1～2 道选择 / 判断题，打卡后出现；答对 +5，答错显示解释，只记第一次作答；选项顺序固定打乱
- **英语单词**：每关 8 个，含例句；点 🔊 用系统语音朗读（iPad 自带，不联网）
- **今天看这条**：首页大按钮直接推荐下一条，看完小测后可一键「下一条」（受能量限制）
- **经验**：看完 +10，动手任务 +30，小测答对 +5，认识一个英语单词 +2；8 个等级
- **徽章**：每关一枚（视频全看完 + 任务完成），另有首次打卡、连续 3 天、英语小达人、动手达人、主线通关
- 进度只存在本机浏览器，换设备请在家长页导出 / 导入；超过 14 天没备份，家长页会提醒
- 家长验证用自制数字键盘（两位数 × 一位数）

## 关于播放

使用 B 站官方嵌入播放器（`player.bilibili.com`），不抓取视频流。嵌入播放器清晰度有限，可点「去 B 站看高清」。
